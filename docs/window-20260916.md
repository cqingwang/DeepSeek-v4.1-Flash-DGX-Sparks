## Correctness / quality on canary2
- needle 262k (198k tokens) PASS; needle 131k PASS on canary; smoke + 16-batch sanity pass.
- sampled (T=1.0/top_p=0.95) decode is 5% slower than greedy in steps/s (17.5 vs 18.5) even
  with `SGLANG_DSPARK_FOLDED_SAMPLING=2`; on the old image both were folded and equal. Text is
  coherent. Without FORCE it was 9% slower (branch folds greedy only by default because the
  V4.1 markov head now does sharded greedy argmax).
- Greedy text equality is NOT a usable criterion on this stack: the stock path gives different
  greedy outputs on identical cold 70k prompts (C vs C3) and cached vs cold (C vs C2). The
  #39187 backports are validated by the CPU equivalence tests (6 scenarios, bitwise) and
  upstream's in-forward page_indices comparison, not by text diffs.

## What is deployed
`IMAGE=dsv41-4x-spark:dsv41-f80c91a4b-20260917` (== `:canary`), built from `Dockerfile.canary`:
base `lmsysorg/sglang:dev-dsv41` + `sglang-kernel 0.4.7` + `sgl-deep-gemm 0.2.0` (PyPI aarch64
wheels) + the dsv4.1 branch python tree at f80c91a4b from a GitHub tarball
(`runtime/sglang-canary/python`) + Mia's SM120 page-split re-applied
(`runtime/flash_mla_sm120.canary.py`) + all adapters. Env: 16 slots, chunk 4096,
`DSV41_ADAPTIVE_CHUNK=0`, `DSV41_INDEXER_CHUNKED=1` (sitecustomize picks v2 for this backend),
`SGLANG_DSPARK_FOLDED_SAMPLING=2`. Rollback documented at the end of `.env.tp4`
(`.env.tp4.pre-canary` is the pre-canary file; old image stays as `dsv41-4x-spark:local`).

## Caveats
- The dsv4.1 branch is mid-refactor upstream (renames on 2026-09-16); a re-pull needs a new
  tarball + re-check of the adapter symbols (all present at f80c91a4b).
- 4k prefill is 6% slower on canary2 than the morning baseline (3174 vs 3390); everything
  from 16k up is faster.
- 16 decode graphs cost ~5.6 GB: available_gpu_mem after capture 13.4 GB (was 19.5).
- 2026-09-17 follow-up from a fresh clone of the public repo: base image prose c1 52.7 / c8 170.1,
  code c1 100.5; canary prose c1 55.2 / c8 176.9, code c1 100.8; needle at 984,559 prompt tokens
  PASS (732 s cold prefill), head MemAvailable low-water 6.64 GiB. The 1M case is covered.
